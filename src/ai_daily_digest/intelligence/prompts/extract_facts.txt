SYSTEM
You extract comparable facts about a subject from a single document
snapshot's text. The field set is closed — see shared/attributes.py — do
not invent new field names.

Rules:
- Only report a fact if its value is explicitly stated in the text below.
  Include the exact supporting sentence or phrase as `quoted_span` — do
  not paraphrase it. This is checked in code: a fact whose quoted_span
  does not actually appear in the text is discarded before storage.
- The `field` property MUST be the exact snake_case key from the closed field
  list below (e.g. `context_window_tokens`, `input_price_usd`, `output_price_usd`,
  `benchmark_scores`, `availability_regions`, `licence_terms`, `modalities`).
  Never use human-readable labels (e.g. "Context window") or informal
  synonyms/abbreviations (e.g. "context_window", "context_window_size") as the field.
- If a field from the closed list is not mentioned in this text AT ALL,
  omit it entirely — do not include an entry with a null or guessed
  value, and do not infer a value from general knowledge. An absent
  fact is a true gap, not something to report.
- If the text EXPLICITLY states that a field's value is being withheld
  or has not yet been announced (e.g. "pricing has not yet been
  announced", "context window details are not disclosed in this
  release"), report it with `"disclosure_status": "not_disclosed"` and
  `"value": null` — never invent a value for it, and never report this
  unless the text actually says so in those terms. This is itself a
  real, citable fact: include the exact sentence stating the
  non-disclosure as `quoted_span`, the same as any other fact. Do NOT
  use `not_disclosed` just because a field happens to be unmentioned —
  that case is the "omit it entirely" rule above, not this one.
- Every other fact (the normal case) uses `"disclosure_status":
  "disclosed"` (the default — you may omit the key) with a real,
  non-null `value`.
- Always include the `value` key on every entry — a real, non-empty
  string for a disclosed fact, or `null` for an explicit non-disclosure.
  Never omit the key.
- confidence reflects how directly the quoted span supports the value
  (1.0 = stated in exact terms, lower = some interpretation was needed).
  Facts below a confidence threshold are discarded in code, not stored.
- Output JSON only, matching the schema below. No prose.

}
Only include entries for fields actually found, disclosed or explicitly
not_disclosed — an empty "facts" list is the correct output when nothing
in the closed list is mentioned, disclosed or otherwise.
